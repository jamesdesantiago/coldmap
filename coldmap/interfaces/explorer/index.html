    About coldmap

    What a finding means

    A finding is a place, method and period where far fewer killings were solved than expected. It is a pattern worth asking about, never evidence that cases are linked. Only investigators can link cases, through DNA, ballistics or other evidence.

    Confidence

    • Detectors agree: two or more detectors found it. In false-alarm tests these rarely appear by chance in most states.
    • Strict: only the strict detector found it, after correcting for testing many combinations.
    • Sensitive: only a sensitive detector found it. Most findings like this appear by chance; treat them as weak leads.

    How to read the data

    • Solved means police had identified an offender when they filed the report. Cases solved later still count as unsolved, so known serial killings still show.
    • Regional findings cover groups of neighboring counties, because offenders cross county lines.
    • Methods are grouped: all firearms together; beating includes blunt objects; strangulation includes asphyxiation.
    • Case lists cover women only. The data has no names or addresses.

    Use it responsibly

    Send leads to the Murder Accountability Project or the investigating agency. Never contact families, witnesses or possible suspects, and never publish a finding as a serial killer.
