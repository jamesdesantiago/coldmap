    How to read this

    A case counts as solved if police had identified an offender when they filed the report. Cases solved later still show as unsolved, which is why known serial killings, such as William Suff's in Riverside County, California (1986–1991), still light up red. A finding is a pattern worth asking about, not evidence that cases are linked. Only investigators can link cases, through DNA, ballistics or other evidence.

    Confidence. Detectors are plug-ins and each is either strict (it controls false alarms) or sensitive (it catches more and is noisier). In the combined view a finding is high when two or more detectors agree, strong when only a strict detector found it, and possible when only a sensitive one did. Tests on shuffled data, where any finding is false by construction, show most possible findings would appear by chance; treat them as weak leads. The list of detectors comes from whatever was installed when this page was built.

    Methods are grouped (all firearms together; beating includes blunt objects and hands; strangulation includes asphyxiation). The case list covers women only. The data has no names or addresses.

    Source: Murder Accountability Project Supplementary Homicide Report file, murders and non-negligent manslaughter only. Built with coldmap. Leads should go to MAP or the investigating agency, never to families or suspects.
